An unsent micro-confession to a dentist: the flossing only ever happened in the parking lot, minutes before the appointment, and the message stayed in drafts because admitting it out loud would undo the whole performance. The To: line and the confession need each other — the same words sent to anyone else would mean nothing.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
